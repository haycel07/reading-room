# 一页之间 Android 1.1.0

最低 Android 8.0（API26），target35。应用ID `chat.tangqichen.onepage`。新版APK `output/android/一页之间-1.1.0.apk`，沿用同一私有签名，可直接覆盖升级保留数据，不要先卸载。

## 阅读与数据

前端资源随安装包内置，导书、阅读、划线、笔记、搜索、书签、统计与简繁副本可离线使用。系统文件选择器只授权所选文件，无广泛存储权限。备份、笔记与翻译导出会打开系统保存窗口，让使用者选择保存位置；文件保存完成后才由系统端提示成功。

书架、笔记、密钥和进度独立保存在此应用，不自动同步电脑或线上站点。新增完整备份支持书籍总量55MB、生成文件80MB以内，恢复为独立副本，密钥不在备份中。

## AI与听书

使用者在阅读设置填写HTTPS API地址、模型名及SK，支持兼容OpenAI Chat Completions的服务。SK默认只存当前WebView会话，可选择仅本设备保存；不会写入源码、日志、APK或备份。1.1.0新增Internet权限，仅AI桥接会向使用者明确填写的HTTPS服务发请求，不向第三方代理转发。电脑Codex仅可在电脑本机阅读器使用。

系统听书使用Android TextToSpeech离线中文音色，支持语速、音调和定时停止。系统没有离线中文语音包时会提示安装。未集成云端TTS或锁屏后台服务。

电子书iframe禁止执行自身脚本；原生桥接只提供固定的AI请求、系统保存文件和离线语音接口，没有任意文件读写、命令执行或通用Java对象暴露。

## 构建

```powershell
cd C:\Users\13\Downloads\biological\reading-room
powershell -ExecutionPolicy Bypass -File android-app\build.ps1 -VersionCode 2 -VersionName 1.1.0
```

构建工具来自官方源，固定哈希校验；不安装Android Studio、不改全局PATH、不自动接受SDK软件包协议。构建复制当前dist，并校验v2/v3签名。Windows PowerShell5的压缩程序集已显式加载。

签名证书及DPAPI加密密码位于 `%LOCALAPPDATA%\OnePageBuild`，不进仓库。必须保留同一签名才能无损覆盖升级。
