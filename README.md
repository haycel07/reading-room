# 一页之间

一个可以舒服读书、划线记笔记，并让「栞」陪你聊已读内容的网页与Android阅读器。默认白色界面，支持TXT、EPUB、PDF等多种格式。

阅读时左上“书架”、右上“设置”始终保留；点击正文中间呼出其他工具。短评以小气泡显示，横屏右侧、竖屏顶部，点击后进入对应聊天。

## 使用

Android安装包与校验文件：[最新发布](https://github.com/haycel07/reading-room/releases/latest)。使用原签名覆盖升级，不先卸载。应用版本与Android版本代码以 [package.json](package.json) 为唯一信源，构建脚本会检查清单中的最终值。

电脑需要Node.js 22或更新版本：

```sh
npm ci
npm start
```

打开终端显示的本机地址（默认127.0.0.1:38751）。这是静态阅读预览，不执行本机Codex。AI可在“设置 → AI服务”里选择API模式，填写自己的HTTPS地址、模型和密钥；网页直连需要服务商允许跨域。密钥默认只存当前会话，可选择仅保存在当前设备，不进入备份。

若要使用本机Codex，已登录Codex CLI的电脑可运行 `node companion-server.cjs`，打开 http://127.0.0.1:38749/ 。此服务只绑定环回地址；允许本机及源码中指定的私有阅读站点来源调用，没有独立用户认证。启动期间，这些受信任页面可以使用本机Codex；不要对局域网开放端口。启动器见 [启动伴读服务.cmd](启动伴读服务.cmd)。

## 伴读与数据边界

自动伴读开启时，会提前发送当前区及符合预备条件的下一区文字，**可能包含未读段落**。界面开关旁有此提示；短评只在读到允许边界后显示。普通聊天使用已读原文或较早内容概括与最近连续原文；资料字段含标题、分隔符不超过24000个UTF-16代码单元，至少保留最近12000单位原文。短文本完整提供。这个字符上限不等于服务商计费token；人物设定、历史、引用和问题另计。

概括可能损失细节，模型也可能利用既有知识猜后文，不能绝对保证防剧透。图片和扫描件没有OCR；PDF复杂排版、电子书分段与阅读速度判断有边界。详见 [触发与上下文说明](伴读触发条件与提示词示例.md)。

书架、进度、笔记、对话和设置保存在当前浏览器来源或Android应用内。电脑本机、线上站点与Android不会自动同步。换设备可使用应用备份；恢复创建独立副本，保留原书，不包含API密钥。
