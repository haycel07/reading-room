# 一页之间

一页之间是一个可以在浏览器和 Android 上使用的中文阅读器。导入一本书后，可以沿目录跳转、划线留笔记，也可以打开伴读，让「栞」在读到特定段落时说一两句。普通阅读不需要账号或 API 密钥。

![从书架打开书本，再返回原书封](output/shared-motion/motion-preview.gif)

## 开始阅读

**Android 8.0 及以上：**从 [1.4.1 发布页](https://github.com/haycel07/reading-room/releases/tag/v1.4.1)下载 APK。已经安装旧版的用户可直接覆盖升级，保留原有书架与进度。安装包的 [SHA-256 校验值](output/android/一页之间-1.4.1.sha256) 可用于核对下载完整性。

**电脑浏览器：**安装 Node.js，在项目根目录打开 PowerShell，运行：

```powershell
New-Item -ItemType Directory -Force companion-work | Out-Null
node companion-server.cjs
```

打开 <http://127.0.0.1:38749/>。第一次体验可以导入[虚构示例书](示例书/小页主动陪读_虚构试读.txt)，试试目录、书签和阅读设置。网页静态资源位于 `dist/`，无需编译前端。

## 阅读与整理

- **导书与定位：**支持 EPUB、PDF、TXT、Markdown、HTML、DOCX 以及部分 MOBI 系格式。阅读左栏提供章节目录和竖向进度条；返回书架后可以从上次的位置继续。
- **摘录与回顾：**给选段划线、加笔记或书签；笔记可导出为 Markdown、TXT 或 CSV。书架可按分组、收藏和阅读状态整理，阅读日历可以按日查看读过的书和时长。
- **阅读设置：**调整字号、行距、版面和动效。Android 可用系统离线语音朗读；可用音色取决于设备已安装的语音包。

## 配置伴读

进入「阅读设置 → AI 服务」，选择服务商或自定义兼容接口，填写地址、模型和 API 密钥。网页与 Android 都能独立配置；网页直连需要服务商允许浏览器跨域请求。助手名称和人物设定可以修改。填写后可点击“测试连接”，用当前输入实际请求模型；测试成功后仍需保存配置。测试只发送一句短文字，不包含书籍。

开启自动伴读后，应用会**提前把当前区及下一区的文字发给所选服务商，其中可能包含尚未读到的段落**。短评在阅读位置到达对应评论点后才显示。详见[触发条件与提示词示例](伴读触发条件与提示词示例.md)。

## 数据与备份

书架、进度、笔记和对话保存在当前浏览器或 Android 应用中，不会自动跨设备同步。换设备前可以导出完整备份，恢复时会创建独立副本。API 密钥默认仅在当前会话保存；选择保存在本机后，也不会随备份导出。
