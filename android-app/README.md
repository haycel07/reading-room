# 一页之间 Android 1.6.0

最低 Android 8.0（API26），target35。应用ID `chat.tangqichen.onepage`。新版APK `output/android/一页之间-1.6.0.apk`，沿用同一私有签名，可直接覆盖升级保留数据，不要先卸载。

## 阅读与数据

前端资源随安装包内置，导书、阅读、划线、笔记、搜索、书签、统计与简繁副本可离线使用。系统文件选择器只授权所选文件，无广泛存储权限。备份、笔记与翻译导出会打开系统保存窗口，让使用者选择保存位置；文件保存完成后才由系统端提示成功。

书架、笔记、密钥和进度独立保存在此应用，不自动同步电脑或线上站点。新增完整备份支持书籍总量55MB、生成文件80MB以内，恢复为独立副本，密钥不在备份中。

## AI与听书

使用者在阅读设置选择服务商、常用模型并粘贴API密钥，地址与模型也可自定义，支持兼容OpenAI Chat Completions的服务。API 密钥默认只存当前WebView会话，可选择仅本设备保存；不会写入源码、日志、APK或备份。1.1.0起使用Internet权限，仅AI桥接会向使用者明确填写的HTTPS服务发请求，不向第三方代理转发。电脑Codex仅可在电脑本机阅读器使用。

系统听书使用Android TextToSpeech离线中文音色，支持语速、音调和定时停止。系统没有离线中文语音包时会提示安装。未集成云端TTS或锁屏后台服务。

电子书iframe禁止执行自身脚本；原生桥接只提供固定的AI请求、系统保存文件、离线语音、阅读醒屏/全屏及由用户点击触发的剪贴板粘贴接口，没有任意文件读写、命令执行或通用Java对象暴露。

1.4.0 新增Motion离线弹簧引擎，书封到阅读页/返回、按钮到面板/弹窗、抽屉、标签、书架FLIP和目录折叠统一过渡。关闭动效与系统减少动态生效；保留六家服务商和常用模型预设、普通遮罩密钥输入与原生粘贴、全面屏/刘海/键盘insets处理、窄屏/横屏/平板布局、书本封面展开动效；保留滑条刻度与1.2.0的白色圆角界面、常驻目录与竖向进度、五类设置、GitHub 式阅读记录、可改名伴读与位置保持。醒屏只在阅读且页面可见时启用，返回书架或应用进入后台会释放。系统返回键可关闭抽屉/设置、退出全屏、返回书架。
